# Sistema de Login

O projeto em questão, trata-se de um Sistema desenvolvido com PHP Orientado a Objetos com o intuito de mostrar as tecnologias, como PHP, POO, PDO, MySQL, jAVASCRIPT,  HTML e CSS. 

## O que o Sistemas faz?

Um sistema cadastra usuários no Banco de Dados, e faz as devidas validações quanto as regras pré-estabelecidas. Como por exemplo, se já existe e-mail cadastrado no Banco de Dados. Logo depois, o usuário tendo seu e-mail e senha cadastrados. Ele já poderá Logar no Sistema, respeitanddo a senha e e-mail inseridos no BD. E, por conseguinte, poderá entrar na Área Restrita e atualizar seus dados, que não é acessível a todos. 

# 🔄 Sync  

Sync é uma aplicação web para sincronização de dados, utilizando PHP e MySQL, projetada para gerenciar e sincronizar informações de maneira eficiente entre diferentes usuários ou sistemas.  

## 🌐 Demonstração  
Acesse a aplicação ao vivo em: [Sync](https://andre-studionerd.github.io/sync/)  

## 🚀 Tecnologias  
- PHP  
- MySQL  
- HTML5  
- CSS3  
- JavaScript  

## ✨ Funcionalidades  
- Sincronização de dados entre usuários e sistemas através de uma interface simples e funcional  
- Armazenamento e gerenciamento de dados utilizando um banco de dados MySQL  
- Comunicação eficiente entre front-end (HTML, CSS, JavaScript) e back-end (PHP, MySQL)  
- Gerenciamento de usuários e dados de forma prática e segura  

## 📥 Como rodar o projeto localmente  
1. Clone o repositório:  
    ```bash
    git clone https://github.com/Andre-StudioNerd/sync.git
    ```
2. Acesse o diretório do projeto:  
    ```bash
    cd sync
    ```
3. Importe o banco de dados MySQL utilizando o arquivo `sync.sql`.  
4. Configure seu servidor local com PHP (como XAMPP, WAMP, ou outro).  
5. Abra o projeto no navegador, apontando para o diretório onde os arquivos PHP estão localizados.
